Control the desktop editor through local MCP, export network images and training bundles, and reuse shared Petri modeling guidance.

## Changes

- New Settings and AI menus, with connection instructions for Codex, Claude Code and Claude Desktop.
- MCP tools operate the editor's existing controls, dialogs and canvas. Connection settings survive application restart.
- Token authentication is optional and off by default. Enable Require token in AI > MCP when needed; generated client configurations follow the selected mode. Connections remain limited to 127.0.0.1 and browser-originated requests are rejected.
- Export the current network as a PNG or save a training ZIP containing PNML, supplied task context, available conversation and observed tool calls, images, geometry and SHA-256 hashes.
- Training bundles retain explicit review and verification status. Credentials are redacted; image geometry is not treated as reviewed training labels.
- Shared modeling skills include guidance for reconstructing networks from photos and diagrams through a vision-capable client.
- Improved dark-theme menus, hover states, toolbar visibility and menu spacing.
- Reusable simulation libraries: `petri-math`, `petri-api` and `petri-model`, with source JARs, POMs and an anonymous Maven repository hosted on GitHub. The server is also available as an executable JAR.

Builds now fetch shared skills from pinned GitHub Release files with SHA-256 verification. A plain Git clone is sufficient.

## Installation

Download the ZIP for your operating system, extract it and run its launcher. Java 23 or newer is required.

For an existing MCP configuration, copy the client setup again after changing the authentication mode. Older saved tokens alone do not enable authentication.
