This portal brings together tools and learning resources for modeling and simulating systems with Petri nets.

## Projects and authors

**PetriObjModelPaint** is the primary desktop project, founded by professor **Inna Stetsenko**. **Petri Net Sim**, its web companion by **Serhii Rybak**, focuses on LLM-assisted model generation alongside editing and simulation.

- [Inna Stetsenko](https://github.com/StetsenkoInna)
- [Serhii Rybak](https://github.com/sergiorbk)
- [PetriObjModelPaint source](https://github.com/StetsenkoInna/PetriObjModelPaint)
- [Petri Net Sim source](https://github.com/sergiorbk/petri-net-sim)
- [Shared modeling resources](https://github.com/sergiorbk/petri-modeling-skills)
- [Portal source and contributions](https://github.com/petri-net-sim/petri-net-sim.github.io)

The Petri Net Sim project originated in Serhii Rybak's 2026 bachelor's thesis at Igor Sikorsky Kyiv Polytechnic Institute, supervised by professor Inna Stetsenko. The project READMEs provide further background.

## Documentation sources

Application guides are imported from the project repositories. Each imported guide links to the exact source revision. Released application documentation follows the latest published release. The shared modeling resources follow their current source revision.

Downloads are resolved from actual GitHub Release assets. Java modules retain their own version numbers. OpenAPI and Java reference documentation are generated during publication.

## Languages and translations

English is the default language. Ukrainian is available through the language selector. Both language versions are written and updated together by contributors and their coding agents. Publication preserves authored translations and reports source changes for review. If a translation is unavailable, the English original is displayed with a notice.
